Sustainable Investment Circle · v1 build plan

The Wayfinder map — from finished prototype to live community

Built with Matt Pocock's /wayfinder skill. The map plans and does not build: every ticket asks one question and its answer is a decision. The UI is already designed — the fog is platform, commercial, privacy and operating decisions.

Destination — the end state of the whole map

A live, production SIC v1 that an ESG professional can join, complete a profile, find and connect with members, message, post in specialist channels, browse research, events and partners, and request Premium — matching the 19 Aug 2026 walkthrough — with enough admin tooling for a small team to run it day to day.

How it works
1Name the destinationFor the whole map, not the first session.
2Breadth-first grillFind the fog. No fog → skip the map, go straight to spec.
3Chart ticketsPrecise questions get a type, a mode (HITL / AFK) and blocking edges.
4One ticket per sessionClaim → decide → resolution comment → close → one line in "Decisions so far" → stop.
5Graduate the fogEach decision clears nearby fog; anything now specifiable becomes a ticket.
6Hand off when clear/to-spec → /to-tickets → /implement. Wayfinder never continues into code.

Decisions so far

  • Members — search + Country · City · Market type · Job role filters
  • Profile — strength meter, PDF download, QR connect, public page
  • Messages & Channels — DMs, private groups, 15 seeded ESG channels
  • Research · Events · Partners — ACSI & RIAA; member-listed events; Harvest by Dasseti
  • Premium — US$99 founding / US$149 annual; external Airwallex link; intelligence + public page

Out of scope

Never graduates on this map — would be a new destination

  • Native iOS / Android apps
  • In-app card capture; any route but the Airwallex link
  • Research marketplace / paid downloads
  • Enterprise SSO; org-level subscriptions
  • AI matchmaking or summaries beyond simple rules
  • Multi-language; public job board

Before you start

Prerequisites and the rules that bite

  • Tracker: GitHub, GitLab or local markdown — not Jira. Use a GitHub repo; native blocking links show the frontier. Mirror to Jira after /to-tickets.
  • Install: npx skills@latest add mattpocock/skills → setup-matt-pocock-skills → /wayfinder
  • Plan only: the prototype looks finished — no "just wiring up" a screen inside the map.
  • Cadence: 26 tickets ≈ 20–25 sessions; research runs in parallel on research/<name> branches.
